# AGENTS.md

## Type annotations

All Python function and method signatures must include type annotations. Tensor shapes are a primary source of silent bugs, so document expected shapes in docstrings when they are not obvious.

## Mathematical notation

Use LaTeX for mathematical notation in notebooks and Markdown, including tensors, layer superscripts, norms, sums, and derivatives.

## Course materials

Link only to the official DeepLearning.AI website and learning platform. Do not commit proprietary course content, solution notebooks, credentials, large datasets, model weights, or generated training outputs without explicit permission.
